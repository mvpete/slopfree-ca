# Submit your own

Think you can do better? Add a file with just the prompt in it, and open a PR:

`prompts/queue/<github-username>-<YYYY-MM-DD>.md`

For example `mvpete-2026-11-20.md`. One a day. Come back tomorrow for another.

Once a maintainer merges it, the weekly search tests submissions oldest first, before drafting its own. Yours faces the same eval as every other prompt. If it loses, it goes in `prompts/openai/losers/` with your name on it and why it lost.
