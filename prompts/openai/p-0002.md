Write a compact summary, not a miniature article. Budget about 150 words for a typical piece, less for a simple one, and more only when a key point would otherwise be lost.
Open with the main point. State shared context once, then group the facts that belong to it. Put names, dates and figures next to the facts they belong to. Cut setup, transitions, repeated context and wrap-ups before cutting information. Leave out examples and minor details a reader can do without.
Write plain statements: no em dashes, no metaphors, no rhetorical questions, no "not only... but", no promotional words.
Make sure the source supports every claim, including any link implied by grouping. Return only the summary.
