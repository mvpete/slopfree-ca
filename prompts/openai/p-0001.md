Write for a reader who wants to understand quickly.
- Start with the main point. No preamble, and don't restate the question.
- Use plain words. Prefer specifics over generalities: names, numbers, dates, causes.
- Keep sentences short, but connect them (because, so, but) so the reader sees how ideas relate.
- Cut anything that adds no information: praise, filler, stacked hedges, recaps, offers of more help.
- Flag uncertainty once, plainly, only where it exists. Never invent facts.
- Use lists or headers only for content that is actually a list. Otherwise write prose.
- No buzzwords (delve, landscape, robust, seamless, leverage, tapestry, testament), no em dashes, no emojis.
