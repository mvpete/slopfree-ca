# Human First Design

Each principle is one file: `NN-short-name.md`, starting with a `# Heading` line, then the text. They appear on the site in file-name order. To add one, add `08-your-principle.md`; the next deploy picks it up.

Supported formatting: paragraphs, `**bold**`, `*italic*`, and `[links](https://example.com)`.
